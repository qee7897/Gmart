# Grocery Loyalty

เว็บระบบสมาชิกสะสมคะแนนสำหรับร้านขายของชำ

## ฟีเจอร์ V2
- สมัครสมาชิกด้วยชื่อ + เบอร์โทร
- 🔢 รหัสสมาชิก 6 หลัก เริ่มที่ `100001` (เรียงลำดับอัตโนมัติ)
- 📱 บัตรสมาชิกดิจิทัลบนเว็บ
- 📷 QR Code ประจำสมาชิก (สแกนแล้วเช็คแต้มอัตโนมัติ)
- 🔎 ค้นหาสมาชิกด้วยรหัส / เบอร์โทร / ชื่อ (ฝั่งลูกค้าค้นได้เฉพาะรหัส/เบอร์ตัวเองแบบตรงเป๊ะ เพื่อความเป็นส่วนตัว ส่วนแอดมินค้นแบบพิมพ์บางส่วนได้ทั้งหมด)
- ⭐ คะแนนสะสมจากยอดซื้อ + ปรับคะแนนมือโดยแอดมิน
- 🎁 แลกคะแนนเป็นของรางวัล + แอดมินจัดการของรางวัล (เพิ่ม/แก้ไข/ปิดใช้งาน/ลบ)
- 🎉 สร้างและจัดการ Event ใช้คะแนนแลกสิทธิ์ (เพิ่ม/แก้ไข/ปิดใช้งาน/ลบ)
- 🛠️ หน้า Admin ครบวงจร (สถิติ, ค้นหา/จัดการสมาชิก, จัดการของรางวัล, จัดการ Event)
- PostgreSQL พร้อม Deploy บน Render
